Trend analysis—not a per-frame benchmark

Adrenalin logs are periodic snapshots, adjustable from 0.25 to 5 seconds. Even at 250 ms, about 15 frames pass at 60 FPS. Use this reader for sustained load, major changes, and broad relationships. Short hitches and individual frame-time spikes may be missed or averaged, so Frame pacing provides a general overview rather than rigorous per-frame analysis.

Diagnostic viewsCPU ↔ GPU compares FPS with total GPU and CPU utilization for initial triage. GPU limits adds GPU clock, board power, and hotspot temperature. Frame pacing groups FPS, frame time, 99th% FPS, and stutter rates. These sampled indicators can reveal relationships but do not prove the processor causing a bottleneck.
Multiple filesOne Hardware and one FPS / latency file can be loaded for a game session. Adding another file of the same type replaces its slot. Files are checked using their filename session IDs and timestamp overlap. Hover uses the nearest logged reading from each file and does not interpolate values.
About statisticsThe top strip shows only graph rows currently in the vertical viewport. Values are calculated from logged samples in the visible time range, not individual rendered frames.
